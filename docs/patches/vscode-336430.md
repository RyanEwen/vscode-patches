# Fix agent feedback review commands in editor windows

Upstream: [microsoft/vscode#336430](https://github.com/microsoft/vscode/pull/336430), fixing [issue #336428](https://github.com/microsoft/vscode/issues/336428).

State on 2026-09-16: **OPEN**. Snapshot head: `07ce4a54bfa9875f769056be4d672122b11e72b1`. Source base: `0a4fc0adc2c7ca7dc85fe5a271cf78f2ec36bc25`.

[Download source patch](../../source-patches/vscode/336430.patch) · [Current upstream patch](https://github.com/microsoft/vscode/pull/336430.patch)

Regular editor windows display the agent-host review confirmation but do not register its comment commands. The renderer logs a command-not-found failure, then incorrectly shows “No unreviewed comments” with Reveal Selected disabled. This was observed in Windows VS Code 1.137.0 connected to WSL; the registration gap also exists in the recorded upstream source base.

The fix registers editor-only handlers backed by the owning host's annotations channel. Host services load lazily. Reads wait for hydration and preserve remote file mapping and peer-chat ownership. Explicit selection is written before approval, empty or stale selections are rejected before mutation, and unchecked pending selections from interrupted reveals are cleared. Loading errors receive a distinct message. The dedicated Agents-window implementation remains separate.
